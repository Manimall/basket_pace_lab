## Методология

Для каждой лиги × период тестировались 4 комбинации фичей:

| Комбо | Описание |
|---|---|
| `BASE` | Rolling stats, matchup deltas, context (home_days_rest и т.д.) |
| `BASE+FATIGUE` | + плотность расписания, B2B, rest_diff |
| `BASE+TEAM_ADV` | + box-score ORtg/DRtg/3PA из Go-скаута |
| `BASE+FATIGUE+TEAM_ADV` | Оба add-on вместе |

**Три целевых периода:**
- **GAME** — полный тотал матча vs. закрывающая линия букмекера (реальный рынок)
- **1Q** — тотал 1-й четверти vs. синтетическая медиана тренировочного сета
- **1H** — тотал 1-й половины vs. синтетическая медиана тренировочного сета

> ⚠️ ROI для 1Q и 1H — **синтетический**: реальных букмекерских линий на эти рынки в базе нет. Метрика показывает предсказательную силу модели, а не реальный беттинговый ROI.

## Ключевые выводы

### 1. Доминация первой половины над полным матчем

Гипотеза о том, что первая половина матча лучше поддаётся прогнозированию, **полностью подтверждена данными**.

Для 8 из 11 лиг AUC в 1H выше, чем в полном матче. Самый яркий пример — EuroLeague:

```
EuroLeague:  AUC (game) = 0.515  →  AUC (1H) = 0.685   (+0.170 пункта)
```

Физическая причина очевидна: в первой половине нет тактических фолов в концовке, нет игры на результат при большом счёте, нет «мусорного времени». Темп определяется реальными тактическими установками, которые наши box-score фичи умеют считать.

NBL (Австралия) достиг AUC 0.725 в 1H — это исключительный результат, сопоставимый с профессиональными беттинговыми моделями топ-уровня.

### 2. Парадокс CBA — нет сигнала в game, есть в первой половине

Самый неожиданный инсайт спринта.

```
CBA:  AUC (game) = 0.459 → UNPROFITABLE (модель предсказывает наоборот!)
      AUC (1H)   = 0.649 → Синт. ROI +16.7%
```

Объяснение: в китайской лиге CBA вторая половина матча систематически искажает итоговый тотал. Легионеры (лимитированное время) часто выходят во втором тайме, тактика меняется, темп становится непредсказуемым. Первая половина — это чистый баскетбол с одинаковыми составами, который наша модель умеет считать.

**Вывод:** CBA остаётся в `UNPROFITABLE_LEAGUES` для game-тоталов. Но на рынке первых половин (при наличии букмекерских линий) CBA может стать приоритетной лигой.

### 3. Аномалия LNB — сильный game, нет сигнала в стартах

LNB (французская Про А) — обратный парадокс:

```
LNB:  ROI (game) = +10.0%  — отличный результат
      AUC (1Q)   = 0.428   — модель не видит стартов
      AUC (1H)   = 0.387   — хуже случайного в первой половине
```

Причина, вероятно, в том, что Про А имеет очень высокую тактическую вариативность в стартовых отрезках — тренеры активно экспериментируют в начале матча. Предсказательный сигнал проявляется только на дистанции полного матча, когда тактика стабилизируется.

**Вывод:** для LNB работаем только в game-рынке, стартовые отрезки игнорируем.

### 4. VTB — полный отказ

```
VTB:  AUC (1H) = 0.272   — значительно хуже случайного
```

AUC ниже 0.5 в 1H означает, что модель систематически ошибается. Возможные причины: малая выборка (188 матчей), специфика российского баскетбола, недостаток box-score данных (TEAM_ADV не помогает). VTB исключается из приоритетов на следующий сезон.
