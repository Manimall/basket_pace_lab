# Эксперимент: просадка тотала в Q4 и её драйверы

**Статус:** NEXT / not started
**Источник:** идея Gemini (ранее) + подтверждено обсуждением 21.07.2026
**Тип:** descriptive → regression на факторах
**Связано:** [[experiment_q1_over_cba]] (Q4 там — контроль), [[experiment_q4_under_after_3_overs]]

---

## 1. Вопрос

Насколько комбинированный счёт **Q4 ниже**, чем в Q1–Q3, и **от каких факторов** это зависит? Это фундамент под все четвертные стратегии: если знаем величину и драйверы просадки Q4, можем отделять «нормальную» просадку от эксплуатируемого перекоса линии.

---

## 2. Данные

Из `QuarterStats` (`period_type='quarter'`), по каждому матчу собрать 4 значения комбинированного счёта:
- `qN_combined` = `home_score + away_score` для `period_number = N` (N = 1..4).
- **Q4:** исключать строки `q4_includes_ot_points = True` (OT-контаминация).

Из `Match`: `total_line`, `went_to_overtime`, `overtime_periods_count`, `league_id`, `season`, `start_time`, `has_quarter_breakdown = True` (фильтр).

---

## 3. Шаг 1 — дескриптив

- Средний `qN_combined` по каждому периоду; **`delta_q4 = q4_combined − mean(q1,q2,q3)`**.
- Распределение `delta_q4` (не только среднее — медиана, хвосты, доля игр где Q4 > среднего Q1–Q3).
- Разбивка по лиге и сезону (CBA в фокусе, но посчитать и остальные лиги для сравнения — CBA может отличаться от NBA/EuroLeague по величине просадки).

## 4. Шаг 2 — драйверы (regression)

Таргет: `q4_combined` (или `delta_q4`). Кандидатные факторы:

| Фактор | Гипотеза влияния |
|---|---|
| **Маржа перед Q4** (`abs(cum_score_home − cum_score_away)` после Q3) | Блоуаут → garbage time. Знак неоднозначен: running clock / сушка ↓, но «мусорная» перестрелка резервов ↑. Померить реально. |
| **Близкая игра** (маржа ≤ 5) | Клатч: меньше владений, больше фолов/штрафных → темп ↓, но очки со штрафных ↑. Нетто? |
| **Общий темп матча** (`total game combined` или `total_line` как прокси) | Быстрые матчи — просадка Q4 меньше или больше в абсолюте? |
| **Pace-тир команд** (топ-квартиль Q1–Q3 pace) | Быстрые команды меньше проседают в Q4? |
| **OT-игры** | Флаг/исключить — клатч-игры системно другие. |
| Home/away, лига, сезон | Контрольные. |

Метод: OLS для интерпретируемости эффектов + GBM (CatBoost, он уже в стеке) для нелинейностей и ранжирования важности факторов. Репортить **величину эффекта в очках**, не только значимость.

---

## 5. Готчи

- **OT** — Q4 только regulation (`q4_includes_ot_points=False`), матчевые агрегаты — regulation-only.
- **`has_quarter_breakdown=True`** — иначе Q1–Q4 нет.
- **Numeric `external_id`** фильтр лиги (известная ловушка).
- Маржа перед Q4 считается из **накопленных** Q1–Q3, а не из финального счёта (иначе смешаешь с самим Q4).
